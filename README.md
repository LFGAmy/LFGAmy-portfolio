# lfgamy.com

The portfolio of Amy Mayernik, developer marketer who builds. I build the communities, creator programs, and events that get AI and developer tools adopted, and the AI systems that run them.

**Live:** [lfgamy.com](https://lfgamy.com)

## What's here

| Path | What it is |
|---|---|
| `index.html` | The site: case studies, The Vault, the system behind the events, and a live terminal wired to my MCP server |
| `event-estimator/` | A free tool to forecast an event before you spend on it: cost per attendee, cost per outcome, and whether you'll hit your target |
| `llms.txt` | A plain-text summary of the site for AI agents and answer engines |
| `SKILL.md` | My profile in the open SKILL.md format, for agents sourcing candidates |
| `invite/` | Personal invitation cards I send to hiring managers |

## Built to be read by people and agents

The site has a terminal that talks to my live MCP server at [mcp.lfgamy.com](https://mcp.lfgamy.com) ([source](https://github.com/LFGAmy/LFGAmy-mcp)). Paste a job description and it gives an honest read of my fit, including where I'd ramp.

## Stack

Static HTML, CSS and JavaScript. No framework. Hosted on Vercel.
